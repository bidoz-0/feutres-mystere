# Reprise – 2026-11-24

## Objectif en cours
Appli web pour téléphone qui propose, pour chaque symbole d'un coloriage mystère Hachette, le feutre le plus proche parmi Languo 240 + GuangNa 168. V1 = 1 livre (Princesses Disney tome 2).

## Fait aujourd'hui
- Cadrage, design et plan : `docs/superpowers/specs/2026-11-24-coloriage-feutres-design.md`, `docs/superpowers/plans/2026-11-24-coloriage-feutres-v1.md`.
- V1 complète, fusionnée dans `main` (PR bidoz-0/feutres-mystere#1) et **en ligne : https://bidoz-0.github.io/feutres-mystere/**
  - Écrans : `app/bibliotheque/`, `app/coloriages/` (liste des pages), `app/nuancier/vue-nuancier.js` (curseur de marque, 5 alternatives, saisie manuelle, doublons).
  - Logique : `app/couleurs/couleur.js` (CIEDE2000), `app/nuancier/proposer.js`, `app/memoire/memoire.js` (localStorage `feutres-mystere:v1`).
  - Données : `data/feutres.json` (408 feutres), `data/livres/princesses-t2.json` (100 pages, 74 nuanciers, dessins des 73 symboles).
  - Outils : `outils/extraire-feutres.html` (images → couleurs), `outils/extraire-livre.js` (PDF → JSON), `outils/table-glyphes.js`, `outils/table-libelles.js`, `outils/corrections.js`.

## État
- Marche : 36/36 tests (`npm test`), parcours complet vérifié dans le navigateur en 375×812, en local et en ligne.
- Pas testé : sur un vrai téléphone ; comparaison complète avec le livre papier (seule la légende de la page 28 a été vérifiée, elle est juste).

## Décisions prises
- Page web statique sans framework ni build : rien à installer, hébergement gratuit (GitHub Pages, dépôt public).
- Couleurs des feutres prises sur les images Amazon (fichiers numériques propres), pas sur les photos des boîtes.
- Symboles reconnus par la forme de leur tracé dans le PDF (ordre non fixe après le 29e) ; l'appli affiche le vrai dessin du symbole.
- Numérotation = pages du livre (« 1 & 2 » pour une double page, un seul nuancier et une seule mémoire de choix).
- Erreurs du PDF corrigées dans `outils/corrections.js` (page 28 : dernière case = ψ, vérifié sur le livre).

## Prochaine étape
Faire tester l'appli sur le téléphone de l'utilisatrice (ajout à l'écran d'accueil) et noter ses retours.

## Pièges
- `sources/` (PDF de Jérémy Mariez, images vendeurs) ne doit jamais entrer dans git : le dépôt est public.
- Ajouter un livre : `node outils/extraire-livre.js sources/pdfs/<fichier>.pdf <id> "<titre>" <nb pages>` ; les nouveaux symboles inconnus arrêtent la CLI → les identifier avec `node outils/apercu-glyphes.js` puis `sources/glyphes.html`, et compléter `table-glyphes.js`.
- Points de robustesse notés en relecture, à traiter avant d'ajouter d'autres livres : regroupement des lignes par `Math.round(y)` (tolérance 1 pt), couleurs CMYK (`k`) ignorées sans erreur, fusion de cases collées de même couleur (`outils/pdf.js`).
- Pas dans la V1 : autres livres, favoris, statistiques (les choix déjà mémorisés permettront de les calculer).
- La branche `feat/v1` est fusionnée ; travailler sur une nouvelle branche pour la suite.
